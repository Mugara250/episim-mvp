# F3 — Scenario Comparison and Geographic Spread

| Topic | Sources say | What we did | Why |
|---|---|---|---|
| Analyst `/scenario` page | Prototype: Epidemiologists got `AnalystScenarios`, which ran the stochastic engine in the browser with its own saved-scenario list and comparison | Retired `AnalystScenarios`, `ScenarioForm` and `ScenarioCompare`. `/scenario` shows the API-backed Scenario Comparison for every role except policymakers (who keep `PolicyScenarios`) | Prompt: no mock engine in the frontend. Docs D5: comparison uses completed runs only and has no run button |
| Comparison page content | Prototype page: hard-coded radar chart, effectiveness bar chart, sensitivity sliders, economic cost and "social disruption" rows | Replaced with docs Module 12: completed-runs list (search, disease filter, non-completed greyed), up to 3 runs, changeable baseline, capacity selector, differences table, fairness and provisional warnings, fan chart with Active cases / Beds needed toggle and dashed beds line, results table with diffs vs baseline, notes + save comparison, copy link | The prototype values were invented. Sensitivity analysis and cost are future work (docs Module 12). The engine has no cost or ICU outputs |
| Comparison URL | Docs: run ids kept in the address | `?runs=a,b,c&capacity=x&baseline=y` | Shareable links. `baseline` added so a changed baseline survives the link |
| Dashboard "scenario comparison" view mode | `ScenarioComparisonView` drew invented curves from mock scenarios | Now a card that links to `/scenario` | Remove mock data without redesigning `Dashboard.tsx` (another worker owns it) |
| Geographic map | Prototype: tile grid plus a Leaflet map with circles. Docs: real boundaries | SVG choropleth drawn with d3-geo (`geoMercator().fitExtent`) from `/api/geographic/districts`. If the boundary file fails, an error card is shown and no shapes are drawn | Prompt section 7 |
| Districts reached in a minority of runs | Docs: show the median; the first-case day is a distribution | Median colours only. A district reached in at least 5% of runs, with a median of 0 cases, gets a hatched, dashed outline and "Reached in N% of runs" in its tooltip and panel | Medians alone hide real spread risk; this shows it without inventing cases |
| Cases colour scale | Docs: fixed scale for the whole run | Log scale from 1 to the run-wide maximum of the median cumulative cases (`scale.maxCumulativeCases` from the API). The same palette as the prototype | Days are comparable; small counts stay visible |
| Beds colour scale | Docs: green < 70%, amber 70–100%, red > 100% | Exactly that, on median hospitalised ÷ district beds. Districts with no bed figure stay neutral, with a prompt to choose a capacity profile | Capacity is a check at analysis time (D4) |
| Timeline start | Prototype started at day 34 | Starts at the last day of the run (the whole picture). Play restarts from day 0 | No arbitrary day |
| Map labels | Prototype labelled every tile | Only the seed and selected districts are labelled on the map; every district has a tooltip and an aria-label | The small Kigali districts would overlap |
| What-if | Prototype: an instant slider on invented curves | A slider for "Start response on day X" plus a **Preview** button calling `POST /simulations/{id}/geographic/what-if`. Shows before → after for the district (cases, beds) and nationally, labelled "Preview · N runs", with a note that the response strengths are placeholders. "Before" comes from the same reduced re-run, so it can differ from the full result shown above it | It is a real reduced re-run (about 1 s); an explicit button avoids firing a run on every slider move |
| "Highest-risk districts" list | Prototype labelled High/Medium/Low from an ad-hoc rule | "Districts to watch" table (District, First case, Cases, Beds with a "short from day N" tag) using the server's `watchList`. No risk labels | Docs Module 9: labels need a defined rule |
| Border chips | Prototype: fixed sample risks | Read from the API (`borderRisks` with `side`), placed west, north, east and south, with a tooltip saying they are assumptions | Docs Module 9 |
| `RwandaMap.tsx` / react-leaflet | Brief: delete once unused | **Kept**: `components/Dashboard/ViewModules.tsx` (not owned by F3) still imports `RwandaMap`. Delete both and remove `react-leaflet` once that view is reworked | Avoid breaking another worker's file |
| PNG export | Prototype used the SVG's pixel size | Uses the viewBox size and stamps "Scenario estimates, not forecasts · Day N · geoBoundaries, CC BY 4.0" on the image | Exported images keep the honesty label and the attribution |
